# V0.5.0 G3 保存、分享与恢复执行记录

状态：完成第一切片

日期：2026-09-26

## 1. 本次目标

在 G2 评分卡和 PNG 导出的基础上，补齐“生成前持久化、文件保存、系统分享、失败分类、取消恢复”的闭环。当前实现保持离线优先，不把 Toy 或浏览器误称为原生相册权限。

## 2. 已完成

- 生成 PNG 或发起系统分享前，将当前游戏草稿与卡片比例/主题写入 `xdrate.games.export-snapshot.v1`；
- 保存结果区分成功、用户取消和写入失败，并保留当前草稿；
- 浏览器/Toy 通过下载式文件保存，桌面继续复用平台文件适配器；
- 支持 Web Share 的环境可直接分享 PNG 文件；不支持图片分享时明确提示先保存 PNG 再从相册分享；
- 分享时检测上次已生成图片的快照是否过期；内容有变动时提供“生成新图片 / 取消 / 分享旧图片”三选一，取消按钮位于中间；
- 分享或保存失败不会清空草稿，也不会丢弃上一次已生成的图片；
- 旧图片仅在当前会话内保留，避免将大体积 PNG 写入 localStorage。快照元数据可用于后续恢复提示。

## 3. 平台边界

“保存 PNG”是当前通用平台的稳定能力；真正写入系统相册需要宿主提供原生 Bridge。Toy/浏览器端不宣称已经取得相册权限。系统分享同样依赖 `navigator.share` 和宿主对图片文件分享的支持。
