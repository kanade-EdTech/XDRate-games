# V0.5.0 MiniTool 游戏版适配执行记录

状态：M0–M1 工程原型完成；等待真实小红书容器与相册权限验收

日期：2026-09-27

## 1. 本次完成

- 新增独立入口 `minitool-game/index.html` 和 `src/minitool-game/main.tsx`；
- 新增 `vite.minitool-game.config.ts`，构建目标为 ES2017 / Chrome 61，资源采用相对路径；
- 游戏版 MiniTool 直接渲染 `GameApp`，不再经过音乐版 MiniTool 入口；
- 游戏评分卡的相册/分享动作接入现有 MiniTool Bridge：`writeTempFile` → `saveImageToPhotosAlbum`；
- Bridge 不存在时保留预览并显示可恢复提示，避免在小红书容器内调用下载链接；
- 为 `html-to-image` 增加仅处理包内 data URI 的离线资源适配，游戏模板封面以内联资源进入 MiniTool 包；
- 修正 MiniTool 审计器对标准 XML 命名空间 `http://www.w3.org/1999/xhtml` 的白名单遗漏；
- 新增 `minitool:game:build`、`minitool:game:audit` 和 `minitool:game:pack` 命令。
