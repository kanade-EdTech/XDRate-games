# V0.5.0 G1 游戏评分编辑器执行记录

状态：完成第一切片

日期：2026-09-26

## 1. 本次目标

将 G0 的游戏模板试验页扩展为可编辑的游戏评分工作区。用户套用模板后，可以编辑当前作品副本，且不会修改内置示例。

## 2. 已完成

- 新增游戏编辑器组件 `GameDraftEditor`；
- 编辑游戏名称、平台、版本/发售年份和发行信息；
- 切换简易、专业和自定义模式；
- 编辑评价轴名称、0–10 分、权重和分项理由；
- 添加、删除评价轴（至少保留一个）；
- 添加、编辑、删除扣分项；
- 编辑总体评价、个人故事和个人签名档；
- 使用现有 `music-linear-100-v4` 评分函数实时计算综合分；
- 当前草稿保存到 `xdrate.games.current-draft.v1`，刷新后恢复；
- 模板目录仍通过深拷贝套用，编辑不会回写 `seeded-example`；
- 新增包名 `xdrate-games@0.5.0`，保持独立游戏产品身份。

## 4. 当前边界

本切片只完成编辑和草稿恢复，不提前接入正式卡片导出、11 种比例、相册保存或平台分享。这些能力在 G2/G3 使用同一个游戏草稿快照接入。
