# XDRate Games 独立仓库开发计划

状态：独立游戏评分器拆分基线

日期：2026-09-26

## 1. 拆分结论

`XDRate-games` 不再把游戏评分作为音乐评分器的条件分支。它是一个独立的游戏评分产品工作区，使用独立的 Toy 入口 `/XDRateGames`。

原音乐仓库 `XDRate-music` 继续维护音乐评分主线；本仓库只保留游戏评分所需的领域模型、模板、封面、评分卡和分享链路。

## 2. 独立产品边界

### 保留

- 游戏作品信息：名称、平台、版本、发行信息、封面和可选备注；
- 简易模式、专业模式和自定义评价轴；
- 个人评分、分项理由、总体评价、扣分项和个人签名档；
- 游戏示例模板：红色警戒 2、使命召唤 4、原神、黑神话：悟空；
- 套用、复制、改名、删除和本地恢复；
- 11 种比例的预览、PNG 导出、相册保存和分享确认；
- 离线优先、本地草稿和 Archive Schema 迁移。

### 明确移除

- `XDRATE MUSIC · BILI TOY` 音乐版头部；
- “多维音乐评价工具”标题和音乐版说明；
- 音乐作品字段、音乐默认模板和音乐版入口；
- 任何通过 URL 查询参数把音乐壳临时切换成游戏内容的方案。

游戏版页面必须从根入口开始就是游戏产品，不允许先渲染音乐外壳再追加游戏模块。

## 3. 版本计划

| 阶段 | 目标               | 主要产物                                     | 完成门槛                      |
| ---- | ------------------ | -------------------------------------------- | ----------------------------- |
| G0   | 仓库与入口拆分     | 游戏版入口、独立标题、版本和隐私文案         | 页面不再出现音乐字样          |
| G1   | 游戏模板与领域模型 | 4 个示例模板、本地模板库、封面清单           | 套用/复制/改名/删除隔离通过   |
| G2   | 正式游戏评分卡     | 评分编辑、理由、扣分项、签名档和 11 比例卡片 | 预览与导出使用同一快照        |
| G3   | 分享与保存闭环     | PNG、相册、系统分享、取消恢复和失败分类      | 离线容器下完整恢复            |
| G4   | 发布验收           | Toy 预览、审计、移动端冒烟和文档             | `/XDRateGames` 只呈现游戏内容 |

## 4. 当前工作状态

- G0–G2 已完成独立入口、游戏模板、编辑器、11 种比例评分卡和 PNG 导出；
- G3 已完成导出前快照、保存/分享、失败分类和取消恢复；
- G4 工程验收已通过，移动端与桌面冒烟、构建和 Toy 内容审计均有证据；
- 当前只剩产品负责人实际预览，以及是否上传/提交审核的显式决策。

## 5. 代码边界

可以复用：评分算法、Archive Schema、卡片渲染器、图片导出器、平台适配器和通用无障碍组件。

必须独立：产品标题、领域字段、默认模板、Toy 入口、领域文案、页面壳和发布构建配置。

共享代码只能通过明确的通用接口复用，不得通过 `domain=game` 查询参数或路径字符串在运行时拼接两个完整产品。

## 6. 后续路线

```text
XDRate Music  继续维护音乐评分主线
XDRate Games  0.5.0 游戏评分试验版
        ↓
1.0.0          动漫独立试验版
1.1.0          微信小程序适配
2.0.0          独立 App 实体
```

游戏版的成功标准是领域评分器和分享闭环可独立发布，不是建立完整游戏数据库或一次性重做所有领域。
